# Publication boundary

This repository is a curated public portfolio view of a much larger local research workspace.

## Included

- original Python research and data-engineering code;
- modeling, market, robustness and paper-tracking modules;
- frozen research configuration;
- methodology and data-contract documentation;
- synthetic test fixtures;
- selected aggregate result summaries;
- CI configuration and test suite.

## Excluded

- raw football datasets;
- provider archives and bulk odds files;
- model binaries;
- API keys and local `.env` files;
- generated prediction tables and large experiment-output trees;
- local caches and execution logs;
- assistant/tool metadata;
- machine-specific provenance;
- the stale V3 2025-completion report whose decision text contradicted the files detected by the audit.

Synthetic public fixtures under `tests/fixtures/` exist only to exercise code paths. They are not research observations.
